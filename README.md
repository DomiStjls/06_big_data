# Аналитика интернет-магазина

**Исследование пользовательской активности и интерактивный дашборд в DataLens.**

Командный учебный проект специализации «Большие данные» Яндекс Лицея. На основе логов интернет-магазина мы подготовили данные, исследовали поведение пользователей и собрали дашборд для анализа продаж, маркетинга и аномалий.

## Какие задачи решает дашборд

| Направление | Что можно исследовать |
| --- | --- |
| Продажи | Динамику выручки, средний чек, конверсию, ARPU и ARPPU; различия между городами и категориями товаров |
| Маркетинг | Активность пользователей, состав аудитории, популярность категорий и поведение в сессиях |
| Аномалии | Необычные изменения активности и распределения сумм по времени и сегментам |

Фильтры позволяют выбирать периоды и сегменты аудитории, а карта — сравнивать продажи по городам.

## Что сделано

- **Подготовка данных:** удаление дубликатов, обработка временных меток и приведение типов.
- **Исследование:** анализ распределений, пользовательской активности, продаж и аномалий.
- **Метрики:** расчёт объёма продаж, конверсии и среднего чека в Python; визуализация бизнес-показателей в DataLens.
- **Дашборд:** отдельные представления для продаж, маркетинга и мониторинга аномалий, фильтры и географический анализ.

**Инструменты:** Python, pandas, NumPy, matplotlib, Jupyter Notebook, DataLens. В общей командной работе также использовались PySpark и ClickHouse.

## Как открыть исследование

1. Скачайте [исходный датасет](https://storage.yandexcloud.net/bigdata-intensive-2023/dataset_telemetry.csv) и сохраните его как `dataset_telemetry.csv` рядом с ноутбуками.
2. Установите библиотеки:

   ```bash
   pip install pandas numpy matplotlib jupyter
   ```

3. Откройте нужный ноутбук через Jupyter и выполняйте ячейки по порядку. Ноутбуки читают исходный CSV независимо друг от друга.

Датасет объёмом более 800 МБ не включён в репозиторий. Для его обработки в pandas потребуется дополнительная оперативная память.
